# 星语塔罗 · 当前实现与验收

更新：2026-10-23。此文记录代码现状；原 [产品设计](README.md) 和 [接口规格](API_AND_DATA.md) 仍包含待完成的服务端要求。

## 已实现

- 星球工具区与设置中的星语入口；独立路由隐藏全局底栏，沿用 Ionic 页面栈。
- 六种方向与固定 1/3/4/5 张牌阵；二选一保持左 A / 右 B，支持任意空牌位先抽。
- 问题、背景、A/B、购物信息与时间范围的本机草稿。进入仪式锁题；“修改问题”确认后以单事务建立新草稿并废弃未翻牌的旧牌组，失败保留原记录；已翻牌历史不可改题换牌。
- 78 张 Web Crypto Fisher–Yates 洗牌、独立正逆位、切牌、圆环手势选牌、飞入牌位及翻牌。抽中结果先提交再播放，拖动和双指手势不选牌；选定任意牌后锁定洗切。
- RWS 本地正逆位关键词与参考牌义；记录保存所用版本与牌面快照，图片随安装包提供。
- 本机历史、搜索、方向/收藏/未完成筛选、20 条逐步展示、收藏、显示标题、个人笔记、删除与清空。
- Android SQLite V5 增量表；浏览器独立 IndexedDB。乐观版本检查、串行保存、事务回滚与删除后的迟到写入保护。
- 三套内置主题与导入主题的塔罗颜色回退；320/390/430px 布局、键盘操作和减少动态效果支持。

## AI 边界

服务端暂未实施，按用户决定留待另一台设备修补。**当前 App 的 AI 默认关闭，无伪造的模型回复。** 关闭时抽牌、卡面、参考牌义、笔记和历史全部可用，聊天页说明尚未接通。

已预留客户端：独立签名 POST 流式传输、严格上下文白名单、版本化数据同意、UTF-8 SSE、分段落盘、取消/超时/未知状态、用户主动恢复和重新请求。私人笔记、显示标题、完整牌序、其他日记及图片不进入模型请求。真实 AI 请求仅允许已配置、已同意的 Android 设备，浏览器预览不会注册生产身份或调用模型；浏览器目前采用离线界面，而非模拟 AI。

进入页面或读取历史不自动生成回复；首次解读需点击按钮。流式超时为首文本 20 秒、文本间隔 25 秒、总时长 90 秒；恢复查询 20 秒。请求原始字节和业务 ID 保存于本机。SSE 正常 EOF 缺少 done 仍是未完成；明确重新尝试使用新 ID 并关联 attemptOf，不自动重生成。

删除已发过 AI 的记录会在同一个事务中留下最小清理待办。已有前台/网络同步触发会处理待办，空队列不联网；失败从 5 分钟起指数退避，最多尝试 3 次，到期后移除。手动清理服务器缓存不删除本机历史。

服务端修补说明、具体路径和启用条件见 [SERVER_REPAIR_HANDOFF.md](SERVER_REPAIR_HANDOFF.md)。服务端额度、真正的模型调用/恢复/清理及最终 Android 网络链路尚未验证。

## 存储与原设计的实现差异

Android 继续使用原 `shiguangjian` SQLite 数据库，版本从 4 增至 5，仅增加 `tarot_readings`、`tarot_drawn_cards`、`tarot_messages`、`tarot_ai_requests`、`tarot_cleanup_outbox` 及索引，不重建日记表。外键级联只作用于塔罗子表。

`src/repositories/sqliteDatabase.ts` 统一管理日记、主题、塔罗和设备身份所用的原生连接与操作队列。多语句事务独占连接直至提交/回滚，其间其他查询和单条写入等待，避免重复创建同名连接或把邮件/身份更新混入塔罗事务。

请求原始 JSON 与状态保存在 `tarot_ai_requests`，当前没有把设计示例的所有诊断字段拆成列；SSE usage/模型/提示词版本等附在消息 metadata 中。清理待办无阅读外键，当前设备身份在真正需要发送时复用原生身份获取，不额外保留设备私钥。服务端对接前应核对实际客户端类型和上下文构建器，不能仅复制设计中的示例 SQL 名称。

浏览器使用 `shiguangjian.tarot.v1` IndexedDB，不迁移或改写原日记浏览器存储；与 Android 不互通。当前没有塔罗导入导出或云端历史，卸载/清除数据会丢失本机记录。
